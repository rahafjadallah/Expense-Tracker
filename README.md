# 💰 Expense Tracker

A simple and responsive Expense Tracker built with HTML, CSS, and Vanilla JavaScript. This application allows users to manage their income and expenses, track their balance, and save transactions using Local Storage.

## ✨ Features

- Add income and expense transactions.
- Enter transaction descriptions and amounts.
- Display total balance, income, and expenses.
- Delete transactions.
- Automatically calculate the balance.
- Save transactions using Local Storage.
- Keep data available after refreshing the page.
- Responsive and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- DOM Manipulation
- Event Listeners
- Array Methods (`map`, `filter`, `reduce`)
- Local Storage
- JSON

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone YOUR-REPOSITORY-LINK
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding your income and expenses!
